Guía de Uso Rápido

Bienvenido al Framework de Pruebas de Base de Datos SQL.

Flujo principal de trabajo:

  1. Proyecto: Seleccione o cree un proyecto activo en el selector superior.
  2. Perfil Oracle: Configure un perfil de conexión. No guardaremos su contraseña por seguridad.
  3. Casos: Escriba las sentencias DML (INSERT, UPDATE, DELETE) e indique la validación esperada (ROW_COUNT o EXISTS).
  4. Suites: Agrupe los casos en una Suite para ejecutarlos en ráfaga.
  5. Ejecución: Inicie la prueba. Si modifica datos, se aplicará ROLLBACK automáticamente.
  6. Historial: Revise detalladamente si los resultados obtenidos coinciden con lo esperado.
Advertencia: No utilice este framework contra una base de datos de producción real.
